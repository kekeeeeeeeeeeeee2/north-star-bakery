# North Star Bakery — Sophia Learning website demonstration

Four-page static website: `index.html`, `products.html`, `about.html`, and `contact.html`. Shared responsive stylesheet: `styles.css`; JavaScript: `script.js`. Bakery media live in `assets/`.

## Upload
Extract this ZIP and upload the contents (not the ZIP itself) to the root of your GitHub repository, preserving `assets/`. In repository Settings > Pages choose Deploy from branch, main, root. Test all four pages and media on the published site.

## Assignment note
This project was assembled using supplied bakery media and may not reproduce the original Touchstone 2 website. Check the official Touchstone 3 rubric, take a real screenshot, and add your actual repository and preview URLs to your submission. The contact form is a demonstration only and does not send messages.
